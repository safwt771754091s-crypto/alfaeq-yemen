# منصة المعلم الذكية — للمعلم اليمني

منصة ويب عربية (RTL) متكاملة ومستقلة للمعلم في اليمن: تحضير الدروس، توليد
العروض التقديمية، التصحيح الذكي، وسجلات الدرجات والحضور والشهادات.
تعمل بلا خادم وتخزّن كل البيانات محلياً في المتصفح (LocalStorage)، وتعمل
كذلك دون اتصال بالإنترنت (PWA).

## المزايا

1. **المنهج اليمني الشامل** — التعليم الأساسي (الصفوف 1–9) والثانوي
   (علمي/أدبي) بموادها ووحداتها ودروسها الرسمية.
2. **التحضير الذكي** — توليد تحضير احترافي (أهداف وفق بلوم، تمهيد، عناصر،
   استراتيجيات تدريس، وسائل وتقويم) مع إمكانية الحفظ والتصدير.
3. **مولّد العروض التقديمية** — شرائح من شريحة العنوان حتى الخاتمة، عرض
   مباشر، وتصدير إلى **PowerPoint (.pptx)** أو Markdown أو الطباعة.
4. **كراسة التحضير الفصلية** — توليد كراسة متكاملة: غلاف رسمي، خطة أسبوعية
   كاملة، مواءمة المنهج (توزيع الوحدات والدروس على الأسابيع)، ونموذج تحضير
   درس، مع حفظ الكراسات وتصديرها (Markdown/CSV) وطباعتها.
5. **التصحيح الذكي** — إدخال نموذج الإجابة والأسئلة (اختيار من متعدد، صح/خطأ،
   مقالي قصير)، تصحيح آلي، تحليل فوري لأخطاء الطلاب، ومقترحات أنشطة علاجية.
6. **سجل الدرجات** — مجاميع ونسب وتقديرات تلقائية مع تصدير وطباعة.
7. **الحضور والغياب** — تسجيل يومي مع إحصائيات وتقارير تراكمية.
8. **مولّد الشهادات** — شهادات تفوق/تقدير/انتظام/مشاركة قابلة للتعديل والطباعة
   بالأسماء تلقائياً، وتوليد لصف كامل.
9. **الصفوف والطلاب والإعدادات** — إدارة الصفوف والطلاب (مع استيراد كشوف)،
   وبيانات المعلم والمدرسة، ونسخ احتياطي/استعادة، وحذف البيانات.
10. **حساب المالك** — الحساب الرئيسي للمنصة: يُنشأ مرة واحدة، محمي برمز دخول
    مُلبَّد محلياً، ويعرض لوحة إحصائية شاملة لكل بيانات المنصة مع إمكانية
    تعديل البيانات وتغيير الرمز وإعادة التعيين.

## التشغيل

```bash
npm install
npm run dev       # وضع التطوير
npm run build     # بناء الإنتاج (يشمل توليد ملفات PWA)
npm run preview   # معاينة حزمة الإنتاج
npm test          # اختبارات المحرّكات (بدون تبعيات)
```

## البنية

```
src/
  data/curriculum.js      المنهج اليمني (مراحل، صفوف، مواد، وحدات، دروس)
  data/strategies.js      استراتيجيات التدريس، مستويات بلوم، أدوات التقويم
  lib/lessonEngine.js     محرّك التحضير + مولّد الشرائح + تصدير PPTX/Markdown
  lib/notebookEngine.js   محرّك كراسة التحضير (خطة أسبوعية، مواءمة، تصدير)
  lib/gradingEngine.js    محرّك التصحيح + تحليل أداء الصف + توليد أسئلة
  lib/utils.js            أدوات مساعدة (تواريخ، أرقام عربية، تنزيل الملفات)
  state/store.jsx         حالة التطبيق والتخزين في LocalStorage
  state/owner.jsx         حساب المالك (رمز دخول مُلبَّد + جلسة)
  pages/                  صفحات المنصة
scripts/engine-test.mjs   اختبارات وحدة للمحرّكات
```

## ملاحظات تقنية

- تصدير PowerPoint يتم بتوليد حزمة OOXML صالحة داخل المتصفح دون أي مكتبة
  خارجية، لذا يعمل التطبيق بلا اتصال بالكامل.
- لا يوجد خادم أو قاعدة بيانات خارجية؛ الخصوصية كاملة والبيانات تبقى على
  جهاز المعلم.
